# Hermes [A second opinion on workflow lessons]

Hermes is an optional, **read-only advisor**. When Pilot proposes a [workflow lesson](/harness/memory#workflow-lessons), Hermes can comment on it before you review it. It cannot accept the lesson, change policy or touch transactions.

- Default off: `PILOT_HERMES_ENABLED=0`. Turning it on is an explicit operator action.
- Pinned to Hermes v0.22.2. Non-Mainnet only.
- Requires your consent in the Memory page (`/api/hermes/consent`).

See `docs/hermes-workflow-integration.md`.
