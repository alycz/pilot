# All operations [95 in production, 103 including local-only]

Call any of these as `harbor.<name>(args)` inside MCP `execute`, or `POST /api/ops/<name>` over REST. Use MCP `search` with the exact name to get its argument signature and a runnable example.

Legend: **owner** = always needs owner approval · **devnet** = Devnet only · **gated** = disabled unless an environment flag enables it · **local** = local profiles only.
