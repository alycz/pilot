# Harbor operation signatures

Generated from the source catalog. Do not edit this page by hand; run `npm run generate` in `services/harbor`, then `npm run catalog` in `docs-site`.

The generated registry contains **109 operations**, of which **101** remain in the production registry after the local-only filter. These counts describe code registration, not live acceptance or permission. Deployment profiles, operation guards, provider configuration, network support, and owner scope can further restrict availability.

Arguments marked `?` are optional in the catalog signature. Search the running MCP catalog for current discovery metadata; inspect the linked source schemas for required enums, bounds, cross-field validation, and authorization. A signature is not a complete JSON Schema.

Use `POST /api/ops/{operation}` with JSON arguments or the corresponding MCP namespace. Hyphenated namespace segments require JavaScript bracket notation, not dot notation. See [first request](/harbor/quickstart), [response envelopes](/mcp/envelope), and [security](/harbor/security).
